🛍️ Landing Page - Loja de Eletrônicos
Este projeto é uma landing page de uma store de eletrônicos, focada em apresentar produtos premium de tecnologia.
Foi desenvolvido com Vite + React + Tailwind CSS, garantindo performance, responsividade e um design moderno.

🚀 Tecnologias Utilizadas
Vite – Build tool rápida e otimizada
React – Biblioteca para criação de interfaces
Tailwind CSS – Framework de estilos utilitários
📌 Funcionalidades
Página inicial moderna e responsiva
Apresentação de produtos premium de eletrônicos
Layout clean e otimizado para conversão
⚡ Como rodar o projeto
# Clone o repositório
git clone https://github.com/jaumm0/Landing-Page---loja-de-eletronicos-.git

# Acesse a pasta do projeto
cd Landing-Page---loja-de-eletronicos-

# Instale as dependências
npm install

# Rode o servidor de desenvolvimento
npm run dev
